# ALU Deploy Agent - Student Attendance Tracker

Video Link: https://drive.google.com/file/d/1E9_q8ZBu66Kgzk7r7qk0_e7RmfNYBQ73/view?usp=sharing

## Project Overview

The Deploy Agent is a Bash script that automates the deployment,
execution, and log archiving of a Student Attendance Tracker.

It helps make deployment repeatable, reduces manual work, and
handles interruptions during deployment.

## Requirements

- Linux environment
- Bash
- Python 3
- zip utility

The script checks for Python 3, zip, and the required template files
before deployment.

## Project Structure

deploy_agent.sh
templates/
    attendance_checker.py
    assets.csv
    config.json

After deployment, the project has this structure:

attendance_tracker_<name>/
    attendance_checker.py
    Helpers/
        assets.csv
        config.json
    reports/
        attendance.log
        absent.log
    archives/
        attendance/
        absent/

The archives directories are created when logs are archived.
The report files are generated by the attendance application.

## How to Run

From the repository directory, run:

    chmod +x deploy_agent.sh
    ./deploy_agent.sh

Choose one of the four menu options.

### Feature 1: Deploy Application

1. The script checks the required environment and template files.
2. Enter a project suffix, such as v1.
3. The deployment directory will be attendance_tracker_v1.
4. If the directory already exists, choose whether to overwrite it.
5. Choose roster option A to copy students from the sample CSV,
   or option B to generate a fresh roster with zero attendance.
6. Choose the number of students when prompted.
7. Optionally update the warning and failure thresholds.
8. The script sets file permissions, verifies the deployment,
   and launches the attendance application.

The default warning threshold is 75 and the default failure
threshold is 50. Threshold values must be numeric and between
0 and 100.

The application and configuration are copied from the templates.

### Feature 2: Run Application

Choose option 2 and enter the suffix of an existing project,
such as v1. The script runs that project's attendance checker.

### Feature 3: Archive Logs

Choose option 3 and enter the suffix of an existing project.

Existing attendance and absence logs are copied into separate
archive directories with timestamped filenames, for example:

archives/attendance/attendance_YYYYMMDD_HHMMSS.log
archives/absent/absent_YYYYMMDD_HHMMSS.log

The script reports the destination paths and handles missing
log files without trying to archive them.

### Feature 4: Exit

Choose option 4 to exit the Deploy Agent.

## Error Handling and Signal Management

The script checks required tools and template files, validates
user inputs, checks existing project directories, and reports
deployment or file-operation errors.

During deployment, Ctrl+C (SIGINT) or Ctrl+Z (SIGTSTP) triggers
the deployment interruption handler. The handler attempts to
compress the incomplete project into a ZIP archive named:

attendance_tracker_<name>_archive.zip

After successful compression, it removes the incomplete project
directory and exits. If archiving fails, the directory is retained
to avoid deleting the only remaining copy.

The deployment signal handler is disabled before the Python
attendance application starts, so it does not manage interruptions
during an attendance-marking session.

## Testing Checklist

- Run bash -n deploy_agent.sh to check Bash syntax.
- Confirm Python 3 and zip are available.
- Deploy a project using roster option A.
- Deploy a separate project using roster option B.
- Test invalid student counts and threshold values.
- Test the existing-project overwrite and abort choices.
- Run the attendance checker and confirm logs are generated.
- Archive logs and check the printed destination paths.
- Test archiving when one or both logs are missing.
- Test interruption using a disposable project name, not a
  project containing work that must be preserved.
- Confirm a successful interruption test creates the ZIP archive
  and removes only the disposable incomplete project directory.
